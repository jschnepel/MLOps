# First Slice B: Dev Bootstrap — Compose, Keycloak, Personas, Ollama Bridge

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One command brings up the development identity and database profile on this Windows machine from a clean clone — PostgreSQL+pgvector and Keycloak 26.8.0 with the `ops-dev` realm, workload clients with audience mappers, all five personas and both tenants, a `view-users` service account, generated secrets outside git — plus the container route to the host's Ollama, a model-pins loader in `core`, and the owner-applied firewall runbook.

**Architecture:** A root `compose.yaml` (project `ops-copilot`, profile `dev`) runs `postgres` and `keycloak` on a bridge network with every published port bound to `127.0.0.1`. Secrets are files under `%LOCALAPPDATA%\ops-copilot\secrets`, generated by `scripts/bootstrap_dev.py`, delivered through Compose `secrets:`; PostgreSQL reads `POSTGRES_PASSWORD_FILE`, and a small bash entrypoint exports `/run/secrets/kc_bootstrap_admin_password` as `KC_BOOTSTRAP_ADMIN_PASSWORD` and every other `/run/secrets/kc_*` file as an `OPS_KC_*` environment variable (outside Keycloak's `KC_*` option namespace) before `kc.sh start-dev --import-realm`, so the committed realm JSON holds only `${OPS_KC_*}` placeholders. Static tests (YAML/JSON structure, bindings, pins, no secret values) run in `check.py` and CI; live tests (token claims, `iss` equality, service-account scope, Ollama bridge) run only with `OPS_LIVE=1` and leave redacted evidence under `reports/bootstrap/`.

**Tech Stack:** Docker Desktop 29.6.2 / Compose v5.3.1 (WSL2 backend), `quay.io/keycloak/keycloak:26.8.0`, `pgvector/pgvector:pg17` (0.8.7), `python:3.13-slim` (helper container for in-network checks), Python 3.13, uv, pytest, pyyaml (dev), pydantic 2 (`core`), Ollama 0.33.3 on the host.

**Spec:** `SPEC_AMENDMENTS.md` (OPS-BUILD-1.3.6) over `BUILD_SPEC.md` — AM-20.1 (roles), AM-20.7 items 5–6 (`view-users` service account, hardcoded-audience mappers, `KC_HOSTNAME`), AM-30 (Keycloak 26.8.x pinned digest), AM-31 (Ollama network exposure, `data/model-pins.json`), AM-70 (no `internal: true` with a published port); BUILD_SPEC §4 (personas), §9, §21, §27; tasks T05, T43, T44 in `handoff/tasks.json` (read their `review_notes`); `docs/reviews/plan-review-r4-2026-10-06.md` (Keycloak `iss` and `host.docker.internal` dry-run facts).

## Global Constraints

- Every published port binds to `127.0.0.1` (AM-31); no `internal: true` network carries a published port (AM-70).
- Images are pinned by digest: `quay.io/keycloak/keycloak:26.8.0@sha256:b0f60d489d51c5d113390bdf5461d4c06e6051be026c05549f2e1e10ec352bcc`, `pgvector/pgvector:pg17@sha256:ac08538c6f8b9904c33c8224c5e5706dbe760aca29db1d096972b4052c22a75d`, `python:3.13-slim@sha256:bf44cdfcb76cd3b41e879bc058fc37ec5872002ccfde7fcb765e218cde0cd79c`.
- No secret is committed and none appears in `docker inspect` environment: secrets travel as Compose `secrets:` files; `environment:` never carries a password or client secret (T05 DoD).
- Secrets live under `%LOCALAPPDATA%\ops-copilot\secrets\<name>` (one file per secret, no trailing newline); `.env` at the repository root is git-ignored (already in `.gitignore`) and holds only paths, ports and URLs.
- Keycloak: `KC_HOSTNAME=http://localhost:18080`, `KC_HOSTNAME_BACKCHANNEL_DYNAMIC=true`, `KC_HTTP_ENABLED=true`, `KC_HEALTH_ENABLED=true`, dev mode (`start-dev`; its embedded database is **ephemeral container storage, no volume**, so every `up` after a `down` re-imports the realm from the committed file with the current secrets — dev profile only). Realm `ops-dev`. Host callers use `http://localhost:18080`; containers use `http://keycloak:8080`. **Never route host callers through `host.docker.internal`** (T05 review note).
- Audience mappers are "Hardcoded audience" mappers whose values come from the parameters `MCP_READ_RESOURCE_URL` and `MCP_WRITE_RESOURCE_URL` (defaults `http://mcp-read:8081/mcp`, `http://mcp-write:8082/mcp`) plus the literal audiences `incident-sim` and `asset-sim` (AM-20.7 item 6).
- Persona Keycloak user IDs are exactly the `user_id` values in `data/seed-ids.json`, so a token's `sub` equals the seeded ID (AM-20.7 item 5b).
- Keycloak is not an application role database (BUILD_SPEC §9): tenants and memberships are seeded later by a `migrator` data migration (T08/T09). Realm roles `requester`, `reviewer`, `reader` exist for display and tests only; Keycloak users carry no tenant attribute (unmanaged attributes are off by default in Keycloak 24+, and tenant data does not belong there).
- Ollama: containers reach it at `http://host.docker.internal:11434`; host processes at `http://127.0.0.1:11434`. The agent never changes firewall rules, `OLLAMA_HOST`, or any other system setting; the runbook is applied by the owner (AM-31). Measured 2026-10-08: container traffic reaches the host from `127.0.0.1`, so the runbook's primary control is a loopback bind, with the firewall rule as fallback.
- `docker compose down -v` is destructive and is never run by a script or a plan step (BUILD_SPEC §21). Plan steps use `docker compose --profile dev down` (volumes kept) when they must stop the stack.
- Python 3.13 workspace rules from Plan A hold: `uv sync --locked` then `uv run python scripts/check.py`; every text file LF without BOM, written with `encoding="utf-8", newline="\n"`; never create files with PowerShell `>`/`Out-File`/`Tee-Object`; captures use Git Bash `PYTHONUTF8=1 … 2>&1 | tr -d '\r'`.

- Live tests are gated by `OPS_LIVE=1` and skip otherwise; `scripts/check.py` and CI run without it. Evidence files under `reports/bootstrap/` contain decoded claims only — **never a raw token, password or client secret**.

```python
"""Static checks on compose.yaml: loopback bindings, digest pins, file secrets, no secret in environment."""

import re
from pathlib import Path

import yaml

COMPOSE = Path("compose.yaml")
DIGEST = re.compile(r"^[\w./-]+:[\w.-]+@sha256:[0-9a-f]{64}$")


def load() -> dict:
    return yaml.safe_load(COMPOSE.read_text(encoding="utf-8"))


def test_project_name_and_profile():
    doc = load()
    assert doc["name"] == "ops-copilot"
    for name in ("postgres", "keycloak"):
        assert doc["services"][name]["profiles"] == ["dev"], name


def test_every_published_port_binds_loopback():
    for name, svc in load()["services"].items():
        for port in svc.get("ports", []):
            assert str(port).startswith("127.0.0.1:"), (name, port)


def test_images_are_pinned_by_digest():
    for name, svc in load()["services"].items():
        assert DIGEST.match(svc["image"]), (name, svc["image"])


def test_no_internal_network_with_published_port():
    doc = load()
    for name, net in doc.get("networks", {}).items():
        assert not (net or {}).get("internal", False), name


def test_compose_environment_carries_no_secret():
    for name, svc in load()["services"].items():
        env = svc.get("environment", {}) or {}
        items = env.items() if isinstance(env, dict) else (kv.split("=", 1) for kv in env)
        for key, value in items:
            if "PASSWORD" in key.upper() or "SECRET" in key.upper():
                assert key.upper().endswith("_FILE") and str(value).startswith("/run/secrets/"), (name, key)


def test_secrets_are_files_under_secrets_dir():
    doc = load()
    assert doc["secrets"], "no top-level secrets"
    for name, spec in doc["secrets"].items():
        assert spec["file"] == f"${{OPS_SECRETS_DIR}}/{name}", (name, spec)
    for svc_name in ("postgres", "keycloak"):
        used = doc["services"][svc_name].get("secrets", [])
        assert used, svc_name
        for s in used:
            assert s in doc["secrets"], (svc_name, s)


def test_keycloak_hostname_settings():
    env = load()["services"]["keycloak"]["environment"]
    assert env["KC_HOSTNAME"] == "http://localhost:${KC_HTTP_PORT}"
    assert env["KC_HOSTNAME_BACKCHANNEL_DYNAMIC"] == "true"
    assert env["KC_HTTP_ENABLED"] == "true"
    assert env["KC_HEALTH_ENABLED"] == "true"
    assert env["KC_BOOTSTRAP_ADMIN_USERNAME"] == "tmpadmin"
    assert "KC_BOOTSTRAP_ADMIN_PASSWORD" not in env


def test_postgres_uses_password_file_and_init_script():
    svc = load()["services"]["postgres"]
    assert svc["environment"]["POSTGRES_PASSWORD_FILE"] == "/run/secrets/postgres_password"
    assert any(v.startswith("./deploy/dev/postgres/init:") for v in svc["volumes"])
```

```bash
#!/bin/bash
# Export the bootstrap admin password as KC_BOOTSTRAP_ADMIN_PASSWORD (Keycloak has no *_FILE variants, T05) and every
# other /run/secrets/kc_* file as OPS_<UPPER-CASED NAME>, outside Keycloak's KC_* option namespace. The realm import

set -euo pipefail
for f in /run/secrets/kc_*; do
  [ -e "$f" ] || continue
  name="$(basename "$f")"
  if [ "$name" = "kc_bootstrap_admin_password" ]; then
    export KC_BOOTSTRAP_ADMIN_PASSWORD="$(cat "$f")"
  else
    export "OPS_${name^^}"="$(cat "$f")"
  fi
done
exec /opt/keycloak/bin/kc.sh start-dev --import-realm
```

```python
"""scripts/bootstrap_dev.py: secret generation is idempotent and never writes inside the repository."""

from pathlib import Path

from scripts import bootstrap_dev as b


def test_secret_names_cover_compose_secrets():
    import yaml

    doc = yaml.safe_load(Path("compose.yaml").read_text(encoding="utf-8"))
    assert set(doc["secrets"]) == set(b.SECRET_NAMES)


def test_generate_secrets_creates_once_and_never_overwrites(tmp_path: Path):
    created = b.generate_secrets(tmp_path, b.SECRET_NAMES)
    assert sorted(created) == sorted(b.SECRET_NAMES)
    before = {n: (tmp_path / n).read_bytes() for n in b.SECRET_NAMES}
    assert b.generate_secrets(tmp_path, b.SECRET_NAMES) == []
    assert {n: (tmp_path / n).read_bytes() for n in b.SECRET_NAMES} == before
    for n, data in before.items():
        assert len(data) >= 32 and b"\n" not in data and b"\r" not in data, n


def test_write_env_is_lf_without_bom_and_has_required_keys(tmp_path: Path):
    env_path = tmp_path / ".env"
    b.write_env(env_path, tmp_path / "secrets")
    raw = env_path.read_bytes()
    assert not raw.startswith(b"\xef\xbb\xbf") and b"\r" not in raw
    text = raw.decode("utf-8")
    keys = {line.split("=", 1)[0] for line in text.splitlines() if line and not line.startswith("#")}
    assert keys == {
        "OPS_SECRETS_DIR",
        "KC_HTTP_PORT",
        "PG_PORT",
        "MCP_READ_RESOURCE_URL",
        "MCP_WRITE_RESOURCE_URL",
        "OLLAMA_BASE_URL_HOST",
        "OLLAMA_BASE_URL_CONTAINER",
    }
    assert "\\" not in text.split("OPS_SECRETS_DIR=", 1)[1].splitlines()[0]  # forward slashes for Compose
    assert "KC_HTTP_PORT=18080" in text and "PG_PORT=15432" in text


def test_default_secrets_dir_is_outside_repo(monkeypatch):
    monkeypatch.delenv("OPS_SECRETS_DIR", raising=False)  # the override is documented; the default is under test here
    d = b.secrets_dir()
    assert "ops-copilot" in d.parts and "secrets" == d.name
    assert Path.cwd() not in d.parents and d != Path.cwd()
```

```python
import secrets as _secrets
import subprocess

    "kc_client_secret_ops_worker",
    "kc_client_secret_ops_mcp_read",
    "kc_client_secret_ops_mcp_write",
    "kc_persona_alex_password",
    "kc_persona_sam_password",
)
ENV_PATH = Path(".env")
KC_HTTP_PORT = 18080
PG_PORT = 15432
MCP_READ_RESOURCE_URL = "http://mcp-read:8081/mcp"
MCP_WRITE_RESOURCE_URL = "http://mcp-write:8082/mcp"
OLLAMA_BASE_URL_HOST = "http://127.0.0.1:11434"
OLLAMA_BASE_URL_CONTAINER = "http://host.docker.internal:11434"


def secrets_dir() -> Path:
    override = os.environ.get("OPS_SECRETS_DIR")
    if override:
        return Path(override)
    base = os.environ.get("LOCALAPPDATA") or str(Path.home() / ".local" / "share")
    return Path(base) / "ops-copilot" / "secrets"


def generate_secrets(directory: Path, names: Iterable[str]) -> list[str]:
    """Create each missing secret file with 43 URL-safe chars (32 random bytes), no newline. Existing files are kept."""
    directory.mkdir(parents=True, exist_ok=True)
    created: list[str] = []
    for name in names:
        path = directory / name
        if path.exists():
            continue
        path.write_bytes(_secrets.token_urlsafe(32).encode("ascii"))
        created.append(name)
    return created


def write_env(path: Path, secrets_directory: Path) -> None:
    lines = [
        "# Generated by scripts/bootstrap_dev.py. Paths, ports and URLs only; secrets are files under OPS_SECRETS_DIR.",
        f"OPS_SECRETS_DIR={secrets_directory.resolve().as_posix()}",
        f"KC_HTTP_PORT={KC_HTTP_PORT}",
        f"PG_PORT={PG_PORT}",
        f"MCP_READ_RESOURCE_URL={MCP_READ_RESOURCE_URL}",
        f"MCP_WRITE_RESOURCE_URL={MCP_WRITE_RESOURCE_URL}",
        f"OLLAMA_BASE_URL_HOST={OLLAMA_BASE_URL_HOST}",
        f"OLLAMA_BASE_URL_CONTAINER={OLLAMA_BASE_URL_CONTAINER}",
    ]
    path.write_text("\n".join(lines) + "\n", encoding="utf-8", newline="\n")


def compose(*args: str) -> int:
    cmd = ["docker", "compose", "--profile", "dev", *args]
    print("$", " ".join(cmd), flush=True)
    return subprocess.run(cmd, check=False).returncode


def main(argv: list[str]) -> int:
    command = argv[0] if argv else "secrets"
    if command not in {"secrets", "up", "down", "status"}:
        print(__doc__)
        return 2
    directory = secrets_dir()
    created = generate_secrets(directory, SECRET_NAMES)
    write_env(ENV_PATH, directory)
    print(f"secrets: {len(created)} created, {len(SECRET_NAMES) - len(created)} kept, in {directory}")
    print(f".env written: {ENV_PATH.resolve()}")
    if command == "up":
        return compose("up", "-d", "--wait", "--wait-timeout", "240")
    if command == "down":
        return compose("down")
    if command == "status":
        return compose("ps")
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```

```python
"""Keycloak token helpers for live tests (stdlib only). Tokens never leave the test process."""

from __future__ import annotations

import base64
import json
import urllib.parse
import urllib.request

REALM = "ops-dev"


def _post_form(url: str, fields: dict[str, str]) -> dict:
    data = urllib.parse.urlencode(fields).encode("ascii")
    req = urllib.request.Request(url, data=data, headers={"Content-Type": "application/x-www-form-urlencoded"})
    with urllib.request.urlopen(req, timeout=20) as resp:
        return json.loads(resp.read().decode("utf-8"))


def token_url(base_url: str) -> str:
    return f"{base_url}/realms/{REALM}/protocol/openid-connect/token"


def token_client_credentials(base_url: str, client_id: str, client_secret: str) -> dict:
    return _post_form(
        token_url(base_url),
        {"grant_type": "client_credentials", "client_id": client_id, "client_secret": client_secret},
    )


def token_password(base_url: str, client_id: str, username: str, password: str) -> dict:
    return _post_form(
        token_url(base_url),
        {"grant_type": "password", "client_id": client_id, "username": username, "password": password},
    )


def claims(access_token: str) -> dict:
    payload = access_token.split(".")[1]
    payload += "=" * (-len(payload) % 4)
    return json.loads(base64.urlsafe_b64decode(payload).decode("utf-8"))
```

```python
import json
import urllib.error
import urllib.parse
import urllib.request


def delete_bootstrap_admin(base_url: str, username: str, password: str) -> str:
    """Delete the temporary master-realm admin using its own token (T43). Returns 'deleted' or 'absent'.

    Keycloak 26.8 answers the password grant for a deleted user with HTTP 400 `invalid_grant` (measured 2026-10-08);
    401 is accepted too in case a later version changes it.
    """
    form = urllib.parse.urlencode(
        {"grant_type": "password", "client_id": "admin-cli", "username": username, "password": password}
    ).encode("ascii")
    try:
        with urllib.request.urlopen(f"{base_url}/realms/master/protocol/openid-connect/token", form, timeout=20) as r:
            token = json.loads(r.read())["access_token"]
    except urllib.error.HTTPError as exc:
        if exc.code in (400, 401):
            return "absent"
        raise
    auth = {"Authorization": f"Bearer {token}"}
    q = urllib.parse.urlencode({"username": username, "exact": "true"})
    with urllib.request.urlopen(
        urllib.request.Request(f"{base_url}/admin/realms/master/users?{q}", headers=auth), timeout=20
    ) as r:
        users = json.loads(r.read())
    for u in users:
        req = urllib.request.Request(f"{base_url}/admin/realms/master/users/{u['id']}", headers=auth, method="DELETE")
        with urllib.request.urlopen(req, timeout=20):
            pass
    return "deleted" if users else "absent"
```

```python
"""Model pins (`data/model-pins.json`, AM-31): the digest the worker must see from Ollama at warm-up, or fail closed.

The digest is the bare 64-hex value Ollama reports in `/api/tags` (no `sha256:` prefix), exactly as `scripts/probe.py`
writes it; one canonical form keeps the T19 comparison a plain string equality.
"""

from __future__ import annotations

import json
from pathlib import Path
from typing import Annotated

from pydantic import AwareDatetime, BaseModel, ConfigDict, StringConstraints, ValidationError

NonEmpty = Annotated[str, StringConstraints(strip_whitespace=True, min_length=1)]
Digest = Annotated[str, StringConstraints(pattern=r"^[0-9a-f]{64}$")]


class ModelPinsError(ValueError):
    """The pins file is missing or malformed; the worker must not start drafting without valid pins."""


class ModelPins(BaseModel):
    """Strict: JSON strings only for every field, timezone-aware `probed_at`, no extra keys."""

    model_config = ConfigDict(frozen=True, extra="forbid", strict=True)

    model: NonEmpty
    digest: Digest
    ollama_version: NonEmpty
    probed_at: AwareDatetime


def load_model_pins(path: Path) -> ModelPins:
    if not path.is_file():
        raise ModelPinsError(f"model pins file not found: {path}")
    text = path.read_text(encoding="utf-8")
    try:
        json.loads(text)
    except json.JSONDecodeError as exc:
        raise ModelPinsError(f"model pins file is not valid JSON: {path}: {exc}") from exc
    try:
        return ModelPins.model_validate_json(text)
    except ValidationError as exc:
        raise ModelPinsError(f"model pins file is malformed: {path}: {exc}") from exc
```
